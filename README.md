# Dimensionality

**Exploring the Future of Artificial Intelligence Through Generalized Probabilistic Models (GPM)**

Dimensionality is an AI-focused technology platform presenting a vision for next-generation artificial intelligence through Generalized Probabilistic Models (GPM). The project explores an alternative architectural direction focused on computational efficiency, scalable intelligence, reduced infrastructure requirements, and more sustainable AI development.

The platform provides an interactive overview of the GPM concept, its proposed architectural advantages, comparative performance metrics, and its long-term vision for advancing artificial intelligence.

**Live Demo:** https://dimensionalitygpm.com/

## Overview

The growing computational demands of modern artificial intelligence systems introduce challenges related to processing efficiency, hardware utilization, energy consumption, and infrastructure scalability.

Dimensionality explores these challenges through the concept of Generalized Probabilistic Models (GPM), presenting a proposed architectural approach intended to improve computational efficiency while supporting increasingly capable AI systems.

The project is designed as an interactive technology and research-oriented website that communicates the underlying vision, architectural concepts, comparative metrics, and potential applications of GPM technology.

Rather than serving as a conventional AI application, the current repository primarily focuses on presenting the technology, its proposed capabilities, and its broader research direction through a modern web interface.

## Project Objectives

- Explore alternative architectural approaches to conventional large-scale AI models.
- Present the concept of Generalized Probabilistic Models.
- Communicate potential improvements in computational and resource efficiency.
- Compare proposed GPM performance metrics against conventional LLM and GAN architectures.
- Present a long-term vision for scalable and energy-efficient artificial intelligence.
- Build an interactive digital platform for communicating advanced AI concepts.

## GPM Architecture and Vision

Generalized Probabilistic Models (GPM) represent the central architectural concept presented by Dimensionality.

The platform explores the possibility of developing AI architectures that improve computational efficiency and reduce the resource requirements associated with large-scale intelligence systems.

The website presents the following architectural objectives:

| Focus Area | Objective |
|---|---|
| Computational Efficiency | Reduce computational overhead |
| Training Efficiency | Explore more efficient model-training approaches |
| Processing Performance | Improve computational throughput |
| Hardware Optimization | Reduce GPU and memory requirements |
| Energy Efficiency | Minimize energy consumption |
| Scalability | Support increasingly capable AI architectures |

The platform also presents a proposed architectural direction involving Quantum-GPM (QPM), exploring probabilistic representations of information and decision-making.

**Note:** The performance figures and architectural advantages displayed on the website represent project-presented claims and should not be interpreted as independently verified benchmarks.

## Getting Started

### Prerequisites

To run the website locally, ensure that you have:

- A modern web browser (Chrome, Firefox, Safari, or Edge).
- Git installed on your system.
- Visual Studio Code or another code editor.
- A local development server (recommended).

For the current static website, Node.js package installation is not required to preview the main HTML page.

Database-related components and TypeScript service files may require additional configuration depending on the functionality being developed or executed.

### Clone the Repository

```bash
git clone https://github.com/Sohum-Nikam/Dimensionality.git
```

### Navigate to the Project Directory

```bash
cd Dimensionality
```

### Open the Project

Open the project directory in Visual Studio Code:

## Running Locally

The main website can be previewed using a local development server.

### Option 1: VS Code Live Server

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Access the locally hosted website in your browser.

### Option 2: Python HTTP Server

If Python is installed, execute:

```bash
python3 -m http.server 8000
```

Open the following address in your browser:

```text
http://localhost:8000
```
